🎧 About This Listening Test

This Computer-Based IELTS Listening Practice Test 5 replicates the official IELTS CBT listening examination. Part 1 is a workplace conversation about an equipment request form. Part 2 is a guided town tour monologue with map labelling. Part 3 is an academic discussion between Ryan and Emma about a research project plan. Part 4 is an academic lecture on film classification and media violence.

All official question types are covered: form completion, table completion, multiple choice, map labelling, plan completion, notes completion. The 40-minute countdown timer mirrors the real test.
